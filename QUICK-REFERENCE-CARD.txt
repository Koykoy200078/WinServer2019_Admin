┌─ DEPLOYMENT FOR NON-DOMAIN PCs ──────────────────────────────────────────────┐
│                                                                              │
│  Step 1: Build everything                                                    │
│  ──────────────────────────────────────────────────────────────────────────  │
│    PS> cd d:\Projects\WinServer2019_Admin                                    │
│    PS> .\Scripts\Build-All.ps1                                               │
│                                                                              │
│  Step 2: Deploy to standalone PCs                                            │
│  ──────────────────────────────────────────────────────────────────────────  │
│    PS> $pcs = @("192.168.2.101", "192.168.2.102", "192.168.2.103")          │
│    PS> .\Scripts\Deploy-Standalone.ps1 `                                     │
│           -ServerIP "192.168.2.45" `                                         │
│           -TargetPCs $pcs `                                                  │
│           -Username "Administrator"                                          │
│                                                                              │
│  Step 3: Start monitoring                                                    │
│  ──────────────────────────────────────────────────────────────────────────  │
│    1. Run: DeploymentPackage\Server\WinServer2019.exe                       │
│    2. Click: "📊 Live Monitoring"                                            │
│    3. Click: "Start Monitoring Server"                                       │
│    4. Wait: 10-30 seconds for clients to connect                             │
│    5. View: Double-click any PC name!                                        │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

└──────────────────────────────────────────────────────────────────────────────┘

┌─ TROUBLESHOOTING ────────────────────────────────────────────────────────────┐
│                                                                              │
│  ❌ Screen not showing?                                                      │
│     → Check PC has green highlight (active)                                  │
│     → Verify "Last Update" timestamp is recent                               │
│     → Close and reopen viewer window                                         │
│                                                                              │
│  ❌ Clients not connecting?                                                  │
│     → Test: Test-NetConnection -ComputerName <ServerIP> -Port 8888          │
│     → Check: Get-ScheduledTask -TaskName "PCMonitorClient"                  │
│     → Verify: Server IP in client config                                     │
│                                                                              │
│  ❌ Deployment failed?                                                       │
│     → Check TrustedHosts: Get-Item WSMan:\localhost\Client\TrustedHosts     │
│     → Verify credentials: Administrator account                              │
│     → Test PSRemoting: Test-WSMan -ComputerName <PC-IP>                     │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
